# Модульная архитектура проекта

Проект реорганизован в модульную архитектуру для обеспечения независимости модулей `home` и `lk`.

## Структура проекта

```
src/
├── modules/
│   ├── home/              # Модуль главной страницы
│   │   ├── components/    # Компоненты специфичные для home
│   │   ├── pages/         # Страницы модуля home
│   │   └── routes/        # Маршруты модуля home
│   │
│   └── lk/                # Модуль личного кабинета
│       ├── components/    # Компоненты специфичные для lk
│       ├── pages/         # Страницы модуля lk
│       └── routes/        # Маршруты модуля lk
│
├── shared/                # Общие ресурсы
│   ├── components/        # Общие компоненты (Loader, CustomCursor и т.д.)
│   ├── hooks/            # Общие хуки
│   ├── types/            # Общие типы
│   ├── api/              # Общие API
│   ├── utils/            # Утилиты
│   ├── store/            # Глобальное состояние (AuthProvider)
│   └── config/            # Конфигурация
│
├── routes/               # Главные маршруты приложения
├── pages/                # Общие страницы (ErrorPage)
└── assets/               # Статические ресурсы
```

## Принципы модульной архитектуры

1. **Независимость модулей**: Каждый модуль (`home`, `lk`) содержит только свои специфичные компоненты, страницы и логику
2. **Общие ресурсы в shared**: Все общие компоненты, хуки, типы, API находятся в `shared/`
3. **Модульные routes**: Каждый модуль имеет свой файл routes, который подключается в главный `AppRoutes.tsx`

## Импорты

### Внутри модуля
```typescript
// Импорт из того же модуля
import Component from "../components/Component";
```

### Из shared
```typescript
// Импорт общих ресурсов
import { useAuth } from "../../../shared/hooks/useAuth";
import Loader from "../../../shared/components/dataDisplay/preloader/Loader";
```

### Из assets
```typescript
// Импорт статических ресурсов
import Logo from "../../../../assets/images/logo_white.png";
```

## Завершение миграции

Для завершения миграции необходимо обновить импорты во всех файлах:

1. **Страницы lk** (`src/pages/lk/**/*.tsx`):
   - Обновить импорты хуков: `../hooks/` → `../../../shared/hooks/`
   - Обновить импорты API: `../api/` → `../../../shared/api/`
   - Обновить импорты типов: `../types/` → `../../../shared/types/`

2. **Компоненты home** (`src/modules/home/components/**/*.tsx`):
   - Обновить импорты общих компонентов: `../../../dataEntry/` → `../../../../shared/components/dataEntry/`
   - Обновить импорты assets: `../../../assets/` → `../../../../assets/`

3. **Компоненты lk** (`src/modules/lk/components/**/*.tsx`):
   - Обновить импорты общих ресурсов на пути к `shared/`

## Преимущества

- ✅ Независимость модулей - изменения в `home` не влияют на `lk` и наоборот
- ✅ Легкая поддержка - каждый модуль изолирован
- ✅ Масштабируемость - легко добавлять новые модули
- ✅ Четкая структура - понятно где что находится
